# Installing CheaterFlag

**Download:** https://github.com/zimilp/cheaterflag/releases/latest/download/CheaterFlag-Setup.exe

1. Open the downloaded file.
   If Windows says **"Windows protected your PC"**, click **More info → Run anyway**.
   (CheaterFlag is safe and never touches CS2 — it just isn't paid-signed.)
2. CheaterFlag opens on a **Setup** page. Click the orange buttons in order:
   1. **Sign in through Steam** — a Steam window opens; sign in there like normal.
   2. **Turn it on** — if it asks, close Steam first (Steam menu → Exit).
   3. **Connect my match history** — usually happens by itself after step 1.
3. Green ticks everywhere = done. CheaterFlag starts with Windows and updates itself.
